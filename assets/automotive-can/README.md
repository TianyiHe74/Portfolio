# Automotive CAN portfolio images

- `pcb-top.png`: unchanged KiCad render from the team's November 2, 2026 Lab 4 review package. Available library models are shown; some custom parts are absent. This is not a photograph or evidence of assembled-board operation. The page frames the board using CSS, without changing the source pixels.
- `pcb-layout.png`: unchanged top-side Gerber preview from the same package. A design illustration, not a fabrication release.
- `two-cut-route.svg`: editable, high-level illustration of the November 10 Pi-led test topology. It summarizes connectivity and is not a wiring or assembly guide.

The page's hardware results come from the November 10 team bring-up and saved-history comparison. The Pi and Nucleos ran the hardware-tested `107269a` firmware/Pi baseline with the `b693c57` Windows launcher. Matching entries 1–3566 compare index, term and event, not local display timestamps. The later retry correction is software-tested, with hardware verification still open in the source record.

Complete course solutions, raw logs, messages and fabrication files are not included in these portfolio assets.
